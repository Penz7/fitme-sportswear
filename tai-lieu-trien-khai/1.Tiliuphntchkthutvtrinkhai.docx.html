Luồng đồng bộ đơn hàng

Trạng thái SAPO:

  • Đặt hàng, Duyệt, Đóng gói -> Chỉ thay đổi số có thể bán
  • Xuất kho, Hoàn thành -> Thay đổi số tồn
  • Hủy đơn -> Thay đổi số tồn + số có thể bán

Danh sách + Nhập hàng -> Nếu thay đổi -> thay đổi

 

Trạng thái pancake:
    + Mới, Chờ hàng, Ưu tiên xuất đơn, Đã xác nhận, Đang đóng hàng -> Chỉ thay đổi số có thể bản

  • Chờ chuyển hàng,  Đã gửi hàng, Đã nhận, Đã thu tiền -> Thay đổi số tồn
  • Đã hoàn toàn bộ, Đã hủy -> Thay đổi số tồn + Số có thể bán

Hồng Cẩm:

  • Trạng thái Pancake: Đã xác nhận —> Trạng thái Sapo: Đẩy qua hãng vận chuyển ( ViettelPost: Cam kết sản lượng 07)
  • Trạng thái Pancake: Chờ hàng —> Trạng thái Sapo: Chờ duyệt

Note: Đơn tạo trên pancake tất cả đều đẩy qua bên vận chuyển ViettelPost

Luồng đồng bộ tồn kho

  1. Triển khai

Trên server Linux/Ubuntu/Centos/Window đều đáp ứng.

+ Bước 1: Cài docker theo trang chủ của Docker:
https://docs.docker.com/engine/install/ubuntu/

+ Bước 2: Download jdk 21 từ trang chủ của Oracle: https://www.oracle.com/java/technologies/downloads/#java21

+ Bước 3: Chạy database

docker run -d  --name my_postgres -e POSTGRES_USER=myuser  -e POSTGRES_PASSWORD=mypassword -e POSTGRES_DB=mydatabase  -p 5432:5432  postgres:16

+ Bước 4: Cấu hình file application.yaml

server:

  port: 8081

spring:

  datasource:

    url: jdbc:postgresql://116.111.210.93:5432/mydatabase

    username: myuser

    password: mypassword

  jpa:

    hibernate:

      ddl-auto: update # Hoặc none + dùng Flyway

    show-sql: true

    properties:

      hibernate:

        format_sql: true

+ Bước 5: Chạy file ứng dụng:
nohup ./jdk21/bin/java -jar sportswear-0.0.1-SNAPSHOT.jar &

Ngoài ra, các cấu hình khác sẽ được đưa ra phiên bản release cuối.
